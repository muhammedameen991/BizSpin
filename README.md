## 📌 Overview

**BizSpin** is a lightweight, zero-dependency web application designed to help developers, creators, and entrepreneurs overcome decision paralysis. Powered by pure **HTML5 Canvas**, **CSS Glassmorphism**, and **Vanilla JavaScript**, BizSpin features an interactive, physics-driven spin wheel loaded with **63+ curated online business opportunities** spanning Micro-SaaS, AI tools, developer utilities, local business digitization, and digital products.

> 🚀 **Live Demo:** Open `index.html` in any web browser or deploy instantly with GitHub Pages!

---

## ✨ Key Features

- 🎡 **Canvas-Powered Physics Wheel:** Animated spin wheel built using the HTML5 Canvas API with realistic ease-out rotation physics.
- 💡 **63+ Curated Business Ideas:** Hand-crafted startup and side-project concepts across 13 distinct industries.
- 🎨 **Modern Cyber/Glassmorphism UI:** Dark theme featuring neon gradients, responsive dual-column layout, and subtle glow effects.
- 💾 **Local Storage Persistence:** Remembers spin counts and maintains a rolling 5-item spin history without requiring account creation.
- 🔍 **Real-time Search & Instant Category Filtering:** Instantly query ideas by keyword, description, or industry category.
- 📱 **100% Fully Responsive:** Flawlessly scales down to small mobile viewports (320px+) with optimized layout stack.
- ⚡ **Zero Dependencies:** No frameworks (React/Vue/Angular), no backend, no databases, and no external API keys required.

## 🛠️ Tech Stack

| Technology | Usage |
| :--- | :--- |
| **HTML5** | Semantic web page structure and accessible markup |
| **CSS3** | Custom properties, flexbox/grid layout, glassmorphism, and neon keyframe animations |
| **Vanilla JS (ES6+)** | State management, search indexing, dynamic UI rendering, and event handling |
| **HTML5 Canvas API** | Rendering vector wheel segments, text labels, needle pointer, and rotation math |
| **Browser LocalStorage API** | Client-side persistence for spin counts and recent history |
